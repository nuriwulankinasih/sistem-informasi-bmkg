# Sistem Informasi BMKG - Modul F-KLIM

Modul F-KLIM merupakan bagian dari Sistem Informasi BMKG yang digunakan
untuk pengolahan, penyimpanan, dan penyajian data klimatologi.

## Modul

- Pengolahan data F-KLIM
- Validasi data
- Penyimpanan data
- Penyajian data pada dashboard

## Struktur

- `backend/fklim/` - proses pengolahan data F-KLIM
- `frontend/fklim/` - tampilan dashboard F-KLIM
- `database/` - struktur database
- `data/` - data lokal pengolahan
- `docs/` - dokumentasi
- `notebooks/` - eksplorasi dan pengembangan pengolahan data
